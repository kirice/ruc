# 🤖 Бот для автоматизации онлайн-игры - Руководство разработчика

## 📋 Что было сделано

### 1. Исправление ошибок импорта
- **emulator/bridge.py**: Добавлен импорт `Any` в `typing` и исправлены аннотации типов возвращаемых значений методов `capture_frame` и `_capture_window_frame`.

### 2. Создание GUI модулей
- **gui/dashboard.py**: Полноценная панель управления с:
  - Выбором активного бота
  - Двумя консолями (флуд и системная)
  - Переключателем режимов работы
  - Визуализацией предсказаний нейросети
  - Классом `TrainerOverlay` для режима записи данных

- **gui/consoles.py**: Менеджер консолей с:
  - Двумя изолированными очередями команд
  - Фильтрацией дубликатов
  - Приоритетами команд
  - Классом `CommandFilter` для безопасности

### 3. Главный файл запуска
- **main.py**: Точка входа приложения с:
  - Настройкой логирования
  - Инициализацией всех компонентов
  - Тестовым запуском системы

## 🏗 Архитектура проекта

```
/workspace
├── main.py                    # Точка входа
├── core/
│   ├── action_loop.py         # Основной цикл бота
│   ├── scheduler.py           # Планировщик задач
│   └── state_machine.py       # Машина состояний
├── emulator/
│   └── bridge.py              # Мост к эмулятору
├── neural_networks/
│   ├── predictor.py           # NN-2: Предиктор кликов
│   ├── detector.py            # NN-1: Детектор объектов
│   └── context_classifier.py  # Классификатор локации
├── gui/
│   ├── dashboard.py           # Панель управления
│   └── consoles.py            # Консоли ввода
├── tools/
│   ├── trainer.py             # Инструмент обучения
│   └── exporter.py            # Экспорт в EXE
├── config/
│   ├── bots/                  # Профили ботов
│   └── maps/                  # Конфигурации карт
└── logs/                      # Журналы событий
```

## 📝 Конфигурация

### Профиль бота (config/bots/profile_*.json)
```json
{
  "bot_id": "default",
  "name": "Default Bot",
  "map_id": "map1",
  "settings": {
    "confidence_threshold": 0.7,
    "action_delay_ms": 100
  }
}
```

### Карта (config/maps/map_*.cfg)
```ini
[map]
id = map1
name = "Forest Valley"

[model]
predictor_path = models/predictor_map1.onnx
confidence_threshold = 0.7

[click_zones]
exclude_0 = 0,0,200,100  # UI элементы
```

## 🐛 Известные ограничения

1. **GUI отключён по умолчанию** - для headless режима работы
2. **Нет реального эмулятора** - требуется BlueStacks или аналог
3. **Модели-заглушки** - требуют обучения на реальных данных
