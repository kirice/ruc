# Rucoy Online Bot — экспериментальный проект автоматизации

Проект представляет собой Python-приложение для экспериментов с компьютерным зрением, управлением эмулятором BlueStacks, сбором кадров и автоматизацией действий.

> **Статус:** репозиторий приведён к единой точке входа и понятной структуре, но это пока не готовый автономный бот. В репозитории нет обученных ONNX-моделей и датасета. Работа с реальным BlueStacks и игровым процессом требует отдельной проверки на Windows.

## Требования

- Windows 10/11
- Python 3.10+ (рекомендуется Python 3.11)
- установленный BlueStacks и доступный ADB — для реального подключения
- зависимости из `requirements.txt`

Установка:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск

Единая точка входа приложения:

```powershell
python main.py
```

При запуске создаются объекты ядра, моста эмулятора, CV-компонентов и планировщика, после чего открывается графическая панель. Инициализация CV-компонентов **не означает**, что веса моделей загружены: файлы моделей должны быть подготовлены отдельно и размещены в `models/`.

## Структура репозитория

```text
.
├── core/                  # Состояния и планировщик команд
├── emulator/              # Мост управления и захвата кадров
├── gui/                   # Splash screen и панель управления
├── neural_networks/       # ONNX-предиктор, детектор и классификатор
├── tools/                 # Сбор данных и вспомогательные инструменты
├── config/                # Профили ботов и конфигурации карт
├── configs/               # Основной YAML-конфиг и загрузчик
├── data/                  # Место для наборов данных (не содержит датасет)
├── models/                # Место для файлов моделей (веса не включены)
└── src/                   # Ранний экспериментальный вариант архитектуры
```

## Что важно знать

- `main.py` — единственная рекомендуемая точка запуска текущей версии.
- `core/scheduler.py` содержит класс `Scheduler`; `core/state_machine.py` — `StateMachine`.
- `neural_networks/predictor.py` содержит `Predictor`; `neural_networks/detector.py` — `Detector`.
- Каталог `src/` сохранён как экспериментальный код. Он не является вторым способом запуска текущей версии и пока не объединён с корневыми модулями: одноимённые файлы реализуют разные варианты логики.
- `tools/trainer.py` отвечает за сбор пар «кадр — клик». `src/training/trainer.py` — отдельный ранний эксперимент по обучению YOLO; это не взаимозаменяемые модули.
- Файлы моделей, скриншоты, локальные базы и логи не хранятся в Git.

## Проверка

Быстрая проверка синтаксиса:

```powershell
python -m compileall -q .
```

Полноценная проверка требует Windows-машины с зависимостями и тестирования подключения к BlueStacks. Синтаксическая проверка сама по себе не подтверждает работу эмулятора, инференса или игровых действий.

## Ограничения текущего состояния

- обученные веса нейросетей и обучающая выборка не входят в репозиторий;
- форматы ONNX-выходов зависят от конкретного экспорта модели и должны быть сверены с её реальными метаданными;
- подключение к BlueStacks и корректность координат ввода требуют проверки на целевом разрешении;
- автоматические тесты ещё предстоит добавить.
